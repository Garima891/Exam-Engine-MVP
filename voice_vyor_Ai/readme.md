# Voice VyorAI – Voice Proctoring & Second-Speaker Detection

**Voice VyorAI** is an AI-powered voice monitoring and audio proctoring system engineered for remote online interviews and evaluations. It detects unauthorized second voices, proxy candidates, and phone speaker playback while robustly ignoring environmental background noise like fans, air conditioners, and traffic.

> **Important:** Automated alerts generated by Voice VyorAI are indicators intended exclusively for **human recruiter review**, never definitive proof of cheating or fraud. Candidates must never be automatically rejected based on system alerts.

## 2. Technology Stack & Component Justifications

| Component | Technology | Why It Is Used | Audio Source |
|---|---|---|---|
| **Noise Reduction** | DeepFilterNet3 | Aggressively eliminates fans, traffic, and room hum without degrading speech formants. | Enhanced for VAD & YAMNet |
| **Speech Detection** | Silero VAD v6 | Highly accurate, low-latency neural voice activity detector that timestamps human speech. | 16 kHz Enhanced audio |
| **Speaker Verification** | SpeechBrain ECAPA-TDNN | State-of-the-art 192-D speaker embeddings for text-independent voice matching. | 16 kHz Unenhanced Raw audio |
| **Sound Scene Tagging** | Google YAMNet | Pretrained AudioSet classifier to identify non-speech events (ringtones, alarms, noise). | 16 kHz Enhanced audio |
| **Replay Spoofing** | Random Forest Classifier | Detects pre-recorded phone playback via 50 acoustic/spectral features (96.88% holdout accuracy). | 16 kHz 6-second windows |
| **Package Management** | UV (`uv`) | Ultra-fast Python virtual environment and dependency manager. | CPython 3.12 |

## 4. Quickstart & Execution Guide

### Prerequisites
- Python 3.12 managed via [UV](https://github.com/astral-sh/uv).
- Everything runs on CPU; no GPU is required.

### 1. Run the Main Pipeline
```powershell
# Option A: Offline WAV File Mode (Recommended for testing without mic)
uv run python src/audio_pipeline.py --file data/enrollment/candidate_test_v2.wav

# Option B: Live Microphone Mode (Records from laptop mic for 20 seconds)
uv run python src/audio_pipeline.py --duration 20
```

### 2. Run Speaker Model Evaluation (Dataset Validation & Thresholds)
```powershell
uv run python src/evaluate_speaker_model.py
```
Outputs:
- Pairwise comparisons: `reports/evaluation_scores.csv`
- Threshold metrics table (FAR, FRR, EER): `reports/threshold_results.csv`

### 3. Run Raw vs. Enhanced Audio Comparison
```powershell
uv run python src/compare_raw_enhanced.py
```
Outputs:
- Comparison analysis: `reports/raw_vs_enhanced_results.csv`

### 4. Run Replay Attack Detection Evaluation
```powershell
# Evaluate on unseen speakers and devices (Holdout set)
uv run python src/evaluate_unseen_replay.py

# Cross-validation on training dataset
uv run python src/evaluate_replay_classifier.py
```

### 5. Run the Automated Test Suite
```powershell
uv run pytest
```

## 5. Evaluation & Performance Highlights

- **Speaker Verification (ECAPA-TDNN)**:
  - Equal Error Rate (EER): **60.0%** at threshold **0.450** on the initial evaluation set.
  - Multi-chunk aggregation prevents single-utterance false alarms by requiring $\ge 2$ mismatched chunks before flagging.
- **Audio Preprocessing (Raw vs. Enhanced)**:
  - DeepFilterNet removes background noise effectively for VAD and YAMNet.
  - Feeding raw audio into ECAPA-TDNN maintains higher speaker discrimination margin than asymmetric preprocessing (+0.0779 vs -0.0145).
- **Replay Attack Detection (Random Forest)**:
  - Cross-validation balanced accuracy: **89.17%** on training corpus.
  - Holdout accuracy on unseen speakers & mobile devices: **96.88%** (31 / 32 correct).

## 6. Ethical & Legal Guidelines

1. **Candidate Consent**: Informed consent must be acquired before capturing enrollment reference audio.
2. **Biometric Retention**: Reference embeddings and audio recordings must be expunged in adherence with GDPR/CCPA guidelines.
3. **Human In The Loop**: System outputs are informational advisory alerts for human recruiters. No candidate may be automatically rejected based on these signals.
